============================================================
STEP 7 — NETWORK IDENTITY
============================================================

The primary identity of a detected wireless access point is:

BSSID

Example:

AA:BB:CC:DD:EE:FF

If:

SSID = HomeWiFi

BSSID = AA:BB:CC:DD:EE:FF

then this BSSID represents the tracked access point.

If the same SSID appears with another BSSID:

SSID = HomeWiFi

BSSID = 11:22:33:44:55:66

treat it as another access point.

Do NOT merge them.

============================================================
STEP 8 — FIRST SEEN / LAST SEEN
============================================================

For every BSSID maintain:

first_seen

last_seen

Example:

BSSID:
AA:BB:CC:DD:EE:FF

First Seen:
2026-08-28 22:30:10

Last Seen:
2026-08-28 23:05:42

If the BSSID appears again:

Update last_seen.

Do NOT change first_seen.

============================================================
STEP 9 — ACTIVE NETWORK STATE
============================================================

Maintain:

is_active

If a BSSID is detected in the current scan:

is_active = 1

If it was previously active but is NOT present in the current scan:

is_active = 0

IMPORTANT:

A network disappearing from a scan does NOT necessarily mean it has been turned off.

Possible reasons include:

- signal fluctuation
- scanning limitations
- temporary environmental conditions
- adapter behavior

Therefore use wording:

"Network no longer detected"

rather than:

"Network disconnected"

or:

"Network shut down"
