# Wi-Fi Network Security Scanner - Requirements
#
# Phase 1 uses Python 3.11+ standard library modules only.
# No external third-party pip packages are required.
#
# Core standard library modules used:
# - tkinter / ttk (GUI interface - bundled with standard Python Windows installer)
# - subprocess (Invoking Windows netsh CLI)
# - threading (Non-blocking background scanning)
# - dataclasses (Network data model)
# - csv (CSV export)
# - re (Regex output parsing)
# - logging (Structured event & error logging)
# - datetime (Timestamping)
# - unittest (Unit testing suite)
